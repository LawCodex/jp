# 国家戦略特別区域を定める政令

平成二十六年政令第百七十八号

内閣は、国家戦略特別区域法（平成二十五年法律第百七号）第二条第一項の規定に基づき、この政令を制定する。

国家戦略特別区域法第二条第一項の政令で定める区域は、次に掲げる区域とする。

- 一　北海道の区域
- 二　北海道帯広市、河東郡音更町、士幌町、上士幌町及び鹿追町、上川郡新得町及び清水町、河西郡芽室町、中札内村及び更別村、広尾郡大樹町及び広尾町、中川郡幕別町、池田町、豊頃町及び本別町、足寄郡足寄町及び陸別町並びに十勝郡浦幌町の区域
- 三　宮城県及び熊本県の区域
- 四　宮城県仙台市の区域
- 五　秋田県仙北市の区域
- 六　福島県及び長崎県の区域
- 七　茨城県つくば市の区域
- 八　千葉県、東京都及び神奈川県の区域
- 九　新潟県新潟市の区域
- 十　石川県加賀市、長野県茅野市及び岡山県加賀郡吉備中央町の区域
- 十一　愛知県の区域
- 十二　京都府、大阪府及び兵庫県の区域
- 十三　大阪府大阪市の区域
- 十四　兵庫県養父市の区域
- 十五　広島県及び愛媛県今治市の区域
- 十六　福岡県北九州市及び福岡市の区域
- 十七　沖縄県の区域
